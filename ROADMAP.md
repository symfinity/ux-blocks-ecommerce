## Details

### 0.1.x — Shop foundations

Basic storefront components, product cards, badges, price display, rating display

### 0.2.x — Product catalog

Product grids, category navigation, filters, sorting, pagination, empty states

### 0.3.x — Product details

Product gallery, variants, attributes, stock status, delivery information, product metadata

### 0.4.x — Shopping cart

Cart items, quantity controls, price summary, vouchers, shipping estimation, order summary

### 0.5.x — Checkout flow

Checkout steps, address forms, shipping methods, payment methods, order confirmation, progress indicators

### 0.6.x — Customer account

Authentication views, account dashboard, addresses, order history, wishlists, saved payment information

### 0.7.x — Merchandising

Cross-selling, upselling, recommendations, recently viewed products, promotional banners, campaign components

### 0.8.x — Storefront polish

Search interface, autocomplete, breadcrumbs, notifications, loading states, responsive refinements, accessibility improvements

### 0.9.x — API stabilization

Component review, naming consistency, documentation, migration guides, deprecation cleanup, testing coverage

### 1.0.x — Stable API

Semver-stable component API, stable markup conventions, stable styling contracts, complete documentation

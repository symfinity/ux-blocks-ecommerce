# Product card

Compact product tile for grids and carousels.

## When to use

Use **ProductCard** inside list sections or marketing cross-sell rows.

## Usage

```twig
<twig:ProductCard title="Classic Tee" price="29.00" />
```

Variant previews render from `config/component-examples/product-card.yaml`.

## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | `''` | Product name |
| `price` | `string` | `''` | Display price |
